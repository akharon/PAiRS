# PAiRS & SaRp

| Project | What it is |
|---|---|
| **[PAiRS](PAiRS/)** | Code-graph index for AI coding agents and developers — a VS Code extension (Copilot Language Model Tools) and a `pairs` CLI over a shared SQLite index. TypeScript, 13 languages. |
| **[SaRp](SaRp/)** | libclang-based C++ refactoring analysis and safe rewrites. Python. |

Use PAiRS to understand a codebase's structure and call chains, then SaRp to apply semantic C++ refactorings.

See [PAiRS/README.md](PAiRS/README.md) to get started, and [.github/CONTRIBUTING.md](.github/CONTRIBUTING.md) to contribute.
